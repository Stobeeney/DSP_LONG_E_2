# DSP Discrete-Time Signals Reviewer

A Gizmo-style study app for **CMPE 30244 Digital Signal Processing, Lectures 5–8** (discrete-time signals, periodicity, energy and power, even/odd decomposition, signal operations, unit step, impulse and ramp).

- 185 questions (multiple choice, true/false, typed answers) and 33 concept flashcards, built from the course reviewer: worked examples, 81 definition and concept questions, and 40 exam-style questions (apply, analyze, spot the mistake)
- **Learn:** adaptive 12-question rounds on your weakest lecture; missed questions come back until you get them right
- **Definitions:** rounds of concept questions only, with no problem-solving
- **Practice test:** exam-style or mixed, timed, with a full answer key
- **Flashcards** and **Fix mistakes**
- XP, daily streak, combos and per-lecture mastery, saved in your browser
- Layouts for phone, tablet/iPad (portrait and landscape) and laptop
- Works offline; light and dark themes with an animated switch

## Run it

```bash
./start.sh        # serves on port 8000 and prints the laptop and phone URLs
```

Open `http://localhost:8000`, or the LAN URL it prints on a phone on the same Wi-Fi.
It's static HTML/CSS/JS, so any static file server works.
